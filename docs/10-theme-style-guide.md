# Style guide тем doomcode

Принято 2026-10-08. Концепт, по которому делаются и проверяются палитры doomcode. Требование пользователя: мягкие цвета, рекомендуемые в дизайне, без резкого контраста между яркими и тёмными. Решения по настройке тем — `docs/09-config-spec.md`.

## 1. Принципы

1. **Спокойно, но читаемо.** Контраст достаточный для долгого чтения и не больше: чёрный на белом (21:1) утомляет так же, как бледный текст.
2. **Фон не бывает чисто белым или чёрным.** Светлый — тёплый кремовый, тёмный — графитовый с лёгкой синевой.
3. **Цвета подсветки одного веса.** Ключевые слова, строки, типы различаются оттенком, а не яркостью: ни один цвет не «кричит» сильнее остальных.
4. **Комментарии тише кода, но читаемы.** Это не фон, а текст, который тоже читают.
5. **Служебное не спорит с текстом.** Выделение, теги, полосы прокрутки — низкий контраст к фону, различие оттенком.
6. **Диагностика заметна, но не тревожна.** Мягкий фон и подчёркивание приглушённым цветом; текст на фоне ошибки читается так же, как основной.
7. **Цвета берём у проверенных палитр** с открытыми лицензиями и указываем источник.

## 2. Числа

Контраст по формуле WCAG 2 (отношение относительных яркостей). Проверяется тестом `TestDoomPalettesContrast` (`editor/theme/doom_test.go`) для каждой палитры doomcode.

| Что | Против чего | Диапазон | Почему |
|---|---|---|---|
| Основной текст | фон окна | 7–12 | не ниже WCAG AAA (7), но заметно мягче 21:1 |
| Текст тега | фон тега | 7–12 | то же |
| Комментарии | фон окна | 4.5–6.5 | не ниже WCAG AA (4.5), тише основного |
| Цвета подсветки (keyword, string, number, constant, type, function, preproc, heading, link) | фон окна | 4.5–9 | читаемы, но не ярче основного текста |
| Выделение | фон окна | 1.1–1.8 | видно, но не режет |
| Основной текст | фон диагностики (error, warning, info, hint) | ≥ 7 | текст под подчёркиванием читается как обычно |

## 3. Палитры

### doom-light — по умолчанию

Смягчённый `acme`: тот же характер (светло-жёлтое тело, голубовато-зелёные теги), но тёплее и без насыщенности, тёмно-серый текст вместо чёрного. Цвета подсветки — приглушённые синий, коричневый, фиолетовый, бирюзовый, одной светлоты.

| Слот | acme (было) | doom-light | Контраст к фону |
|---|---|---|---|
| фон окна | `#FFFFD5` | `#FBF8E8` | — |
| фон тега | `#D5FFFF` | `#E4F1EF` | — |
| текст | `#000000` | `#3A3A34` | 10.7 (было 20.5) |
| выделение | `#EEEE9E` | `#ECE4B0` | 1.2 |
| комментарий | `#6B7F6B` | `#646F61` | 4.9 (было 4.2 — ниже AA) |
| keyword / string / number / type | `#1F3A93` `#8B4A1F` `#6A2E8F` `#1C6E6E` | `#35539A` `#94552B` `#7A4C98` `#2E716F` | 5.3–6.9 (было 5.9–9.8) |

### doom-dark

По мотивам **doom-one** из [doom-themes](https://github.com/doomemacs/themes) (Henrik Lissner, MIT) — тема официального сайта Doom Emacs (doomemacs.org; doomemacs.com с проектом не связан). Фон `#282C34`, теги `#21242B`, текст `#BBC2CF` (7.8), курсор и ключевые слова синие `#51AFEF`, строки зелёные `#98BE65`, числа оранжевые `#DA8548`, типы жёлтые `#ECBE7B`, функции пурпурные `#C678DD`, константы фиолетовые `#A9A1E1`. Отличие от оригинала: комментарии `#959CA9` вместо `#5B6268` (у doom-one 2.4:1, ниже минимума), фоны диагностики затемнены, чтобы текст на них оставался не ниже 7:1.

### Остальные

`acme`, `vampira`, `solarizedlight`, `solarizeddark` остаются как есть для желающих. Под этот style guide не подгоняются: `acme` — оригинал, Solarized — чужая выверенная палитра.

## 4. Как добавлять тему

1. Взять за основу палитру с открытой лицензией, указать источник и лицензию в комментарии.
2. Заполнить все слоты (`tag.*`, `text.*`, `ui.*`) и все стили из `docs/configuration.md`.
3. Проверить числа §2 — добавить палитру в `TestDoomPalettesContrast`; подогнать цвета, а не диапазоны.
4. Снять кадр: `docs/images/screenshot/shoot.sh <палитра> 1600x1000 out.png` и сравнить с `doom-light`/`doom-dark`.

Пока темы живут в коде (`editor/theme/doom.go`); по `docs/09` §6 они переедут в файлы `config/themes/`, правила те же.
